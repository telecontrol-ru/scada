# Параметры server.json
{:.no_toc}

* TOC
{:toc}

Системные параметры задаются в файле параметров процесса (`server.json` в тексте этого раздела). Расположение файла по умолчанию описано в параметре [`--param`]({{ '/server/' | relative_url }}#параметры-командной-строки).

**ВНИМАНИЕ:** под Windows файлы параметров создает [`scada-setup`]({{ '/server/setup/' | relative_url }}), и каждый `scada-setup apply` — в том числе при каждом обновлении — создает их заново из шаблонов. **Не правьте `server.json`**: записывайте свои параметры в `server.override.json` в той же папке, который `apply` накладывает поверх шаблона (смотрите [Свои параметры]({{ '/server/setup/' | relative_url }}#server-override)).

В параметрах допускается использование переменных подстановки:

| Переменная | Описание |
|---|---|
| `${DIR_PARAM}` | Папка файла параметров |
| `${DIR_EXE}` | Папка исполняемого файла сервера |
| `${DIR_TEMP}` | Временная папка |
| `$ENV{ИМЯ}` | Значение переменной окружения `ИМЯ` (пустая строка, если она не задана) |

Чтобы увидеть полный правильный файл параметров процесса, создайте его
командой `scada-setup generate --tiers <процессы> --output <папка>` (на
компьютере без `scada-config` — также с `--central <адрес>`): она только
записывает файлы в указанную папку и ничего не устанавливает. Составлять
файл параметров с нуля не рекомендуется — в нем должны быть, в частности,
блок [`license`]({{ '/server/licensing/' | relative_url }}) с путем к файлу лицензии,
[`security.rootPassword`]({{ '/server/security/' | relative_url }}#root-password) у процессов `scada-config` и
`scada-filesystem` и включенный
[`opcua`]({{ '/server/opcua/' | relative_url }}#opcua), по которому процессы обмениваются данными.
