# Пользовательская таблица
{:.no_toc}

* TOC
{:toc}

Пользовательская таблица — это окно с электронной таблицей для мониторинга и отображения данных в произвольном табличном формате. Столбцы обозначаются буквами (A, B, C...), строки — числами (1, 2, 3...).

Для создания пользовательской таблицы выберите меню *Таблица — Новая произвольная таблица*.

Пользовательскую таблицу нельзя распечатать или экспортировать в CSV.

## Строка формул

В верхней части окна располагается строка формул. При выделении ячейки в строке формул отображается ее содержимое. Для редактирования ячейки следует выделить ее и ввести текст или формулу в строке формул, либо дважды кликнуть по ячейке.

Для подтверждения ввода нажмите *Enter* или *Tab*.

## Ячейки

Ячейки могут содержать:
* Текстовые значения
* Ссылки на объекты данных (формулы) — значения обновляются в реальном времени
* Математические выражения

При привязке ячейки к объекту данных ее значение обновляется автоматически при изменении данных на сервере.

## Режим редактирования

Редактирование ячеек доступно только в режиме редактирования, который включается командой *Редактирование*. Команда доступна только пользователям с правом «Настройка конфигурации» (права 1 и 3); с правами «0 — Руководитель» таблицу можно только просматривать. В режиме редактирования из контекстного меню доступна команда выбора цвета фона (см. ниже).

## Форматирование

В режиме редактирования контекстное меню ячеек содержит одну команду —
*Цвет...*: она задает **цвет фона** выделенного диапазона ячеек. Других команд
оформления (выравнивания, условного форматирования, вставки и удаления строк и
столбцов) в Клиенте нет.

## Размер таблицы

Пользовательская таблица всегда содержит 100 строк и 100 столбцов; изменить
ее размер нельзя.

## Мигание ячеек

Ячейки, значения которых изменились, могут мигать для привлечения внимания оператора.
