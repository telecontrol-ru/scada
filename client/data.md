# Данные
{:.no_toc}

* TOC
{:toc}


Окно `Данные` отображает историю изменения значений выбранного объекта в виде таблицы с колонками:

| Колонка | Описание |
|---------|----------|
| Метка времени источника | Время значения у источника (с точностью до миллисекунд) |
| Значение | Значение объекта |
| Достоверность | Признак качества значения |
| Метка времени сервера | Время получения значения Сервером |

Каждая строка — одно записанное в архив изменение значения. Окно строится по
архиву Сервера: для объекта без архива значений за прошедшие периоды строк не
будет (смотрите [Отчёты и анализ]({{ '/client/reports/' | relative_url }}#archive)).

Щелчок по заголовку первого столбца переключает порядок сортировки записей по времени (по возрастанию или убыванию).

## Период {#period}

Период задается командами группы *Период* на панели команд — смотрите
[Выбор периода]({{ '/client/reports/' | relative_url }}#period). У нового окна
период — *Сутки*. Период сохраняется вместе с окном.

Если выделить в таблице две строки или больше и выбрать *График* или
*Сводка*, окно откроется за промежуток от первой до последней выделенной
строки.

## Печать и экспорт {#print-export}

Окно можно [распечатать]({{ '/client/print/' | relative_url }}) и
[экспортировать]({{ '/client/export/' | relative_url }}) в CSV командами
*Печать* и *Экспорт в CSV*. Распечатка и файл содержат строки в текущем
порядке сортировки, но не название объекта и не период — укажите их сами.
