# Отладчик
{:.no_toc}

* TOC
{:toc}


Отладчик показывает запросы, которыми Клиент обменивается с Сервером, и
служит для диагностики этого обмена — например, по просьбе службы поддержки.
Обмен Сервера с устройствами в нём не виден: для этого служит окно
[Наблюдение]({{ '/client/device-watch/' | relative_url }}).

## Как открыть {#open}

Отладчик есть только в Клиенте, запущенном с параметром командной строки
`--debug` (например, добавленным в свойствах ярлыка Клиента после пути к
программе). При обычном запуске его пунктов в меню нет.

В Клиенте, запущенном с `--debug`, в меню **Справка** появляются два пункта:

<dl>

<dt>Отладчик</dt>
<dd>Открывает отдельное окно «Отладчик» с вкладкой «Запросы».</dd>

<dt>Отладочная информация</dt>
<dd>Копирует в буфер обмена служебные сведения о выделенном объекте и
сообщает «Отладочная информация скопирована в буфер обмена.». Пункт
доступен, когда выделен объект с данными.</dd>

</dl>

## Окно «Отладчик»

Над таблицей запросов расположены кнопки «Пауза» (во время паузы —
«Продолжить»), «Очистить», поле «Фильтр по имени или ID» и кнопка «Сохранить
трассу», которая записывает показанные запросы в текстовый файл.

Столбцы таблицы в текущей версии подписаны по-английски:

| Столбец | Описание |
|---------|----------|
| ID | Идентификатор запроса |
| Phase | Состояние запроса |
| Start Time | Время отправки запроса |
| Duration | Время выполнения запроса, в миллисекундах (`ms`) |
| Title | Описание запроса |

При выделении строки справа отображается полное содержимое запроса и ответа.

Таблица хранит не больше 1000 последних запросов; более ранние удаляются.
Пока включена пауза, новые запросы в таблицу не записываются.
