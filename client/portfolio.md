# Портфолио
{:.no_toc}

* TOC
{:toc}

Портфолио (ниже — портфель) — это именованная коллекция объектов данных, объединенных пользователем для удобства мониторинга и анализа. Портфели отображаются в виде иерархического дерева: корневые узлы — портфели, дочерние — включенные в них объекты.

Панель портфелей находится в режиме *Объекты* на
[панели разделов]({{ '/client/workbench/' | relative_url }}#activity-bar), под
деревом объектов; ее также открывает команда *Дополнительно — Портфолио*.

![Панель портфелей]({{ '/img/portfolio.png' | relative_url }})

*Панель портфелей: два портфеля и входящие в них объекты.*

## Где хранятся портфели {#storage}

Портфели хранятся в **профиле пользователя**, как раскладка окон и
настройки, — а не в конфигурации Сервера:

* портфели **личные**: другие пользователи их не видят, и передать портфель
  коллеге нельзя — ему придется собрать такой же самому;
* профиль сохраняется на этом компьютере; кроме того, при закрытии Клиент
  сохраняет профиль и на Сервере, в профиле вашей учетной записи, а при
  входе загружает его оттуда — поэтому портфели доступны вам на любом
  компьютере, где вы входите под своей учетной записью. Это относится к любым
  [правам доступа]({{ '/dev/users/' | relative_url }}#access-rights), в том
  числе к учётной записи без ролей. С Сервером 2.5.7 профиль на Сервере не
  хранится: портфели остаются на этом компьютере, отдельно для каждой
  учётной записи, а после обновления Клиента у каждой учётной записи
  начинаются заново — прежние портфели не переносятся (смотрите
  [Передача смены]({{ '/client/' | relative_url }}#shift-change)).

## Создание портфеля

Для создания нового портфеля выберите команду *Создать портфолио* в контекстном меню панели портфелей. Имя портфеля генерируется автоматически и сразу открывается для редактирования.

## Переименование

Для переименования портфеля выберите команду *Переименовать* из контекстного меню портфеля.

## Добавление объектов

Объекты добавляются в выделенный портфель из панели объектов (переключателем
напротив объекта) или командой *Добавить объекты...* из контекстного меню
портфеля.

Портфель — это набор, а не упорядоченный список: каждый объект входит в него
один раз, а показываются объекты в порядке, который задает сам Клиент, — не в
порядке добавления. Изменить этот порядок нельзя.

## Сводка и графики по портфелю {#open}

Выделите портфель и выберите в контекстном меню
*Сводка*, *График* или *Таблица* — откроется окно со всеми объектами
портфеля. Выделив один объект портфеля, можно открыть окна только для него.
Как построить отчёт, описано в разделе
[Отчёты и анализ]({{ '/client/reports/' | relative_url }}).

## Удаление

Команда *Удалить* в контекстном меню удаляет выделенный объект из портфеля, а если выделен сам портфель — портфель целиком. При удалении объекта из системы он автоматически удаляется из всех портфелей.

Перед удалением Клиент спрашивает подтверждение: для портфеля — «Удалить портфолио «…» вместе со списком объектов? Отменить удаление нельзя.», для объекта — «Убрать «…» из портфолио «…»?». Удаление выполняется только по ответу «Да»; кнопка «Нет» выбрана по умолчанию.

**ВНИМАНИЕ:** отменить удаление нельзя — удалённый портфель можно восстановить, только собрав заново.
