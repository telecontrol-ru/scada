{%- comment -%} Consent-gated Google Analytics for the manual. DO NOT replace this with the theme's built-in `ga_tracking` setting. Just the Docs' own `_includes/head.html` loads gtag.js unconditionally when `site.ga_tracking` is set — before the reader has agreed to anything, and with no way to decline. That is exactly the behaviour this file exists to avoid, so `ga_tracking` is deliberately left unset in `_config.yml`; the key read here is `analytics_measurement_id`. Nothing is fetched from Google until the reader accepts. The decision is kept in localStorage under the same key and the same record shape the web client uses (`web/apps/app/src/services/analytics.ts`), which is not incidental: the manual and the embedded client copy under /app/ are served from one origin, so one answer covers both and the reader is asked once rather than twice. Kept in vanilla JS with no build step, matching the rest of this Jekyll site. {%- endcomment -%} {%- assign ga_id = site.analytics_measurement_id | strip -%} {%- if ga_id != "" -%} {%- endif -%}
