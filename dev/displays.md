## Свойства элемента

Пункт `Свойства элемента` вызывается из контекстного меню для выделенной группы объектов по нажатию ПКМ:

![]({{ '/img/menu-parameters-elements.png' | relative_url }})

Табличный режим редактирования параметров объектов упрощает работу со множеством объектов. В этом режиме объекты расположены в строках таблицы, а их различные параметры отображаются в столбцах:

![]({{ '/img/menu-parameters-elements-copy.png' | relative_url }})

Доступно тиражирование ячеек растягиванием выделения за нижний правый угол, аналогично таблицам в MS Excel. Если содержимое ячейки оканчивается числом, оно будет изменяться автоматически. При растягивании вниз число будет увеличиваться, при растягивании вверх - уменьшаться. Чтобы отключить автоматическое изменение ячейки необходимо удерживать клавишу *Ctrl* при растягивании за нижний правый угол.

Из контекстного меню таблицы доступны операции *Копирования* и *Вставки* объектов.

## Электронные схемы Модус

Мнемосхемы — файлы с расширением *sde* и *xsde* — **создаются и
редактируются в Графическом редакторе Модус**. Редактор не входит в поставку
ОИК: это отдельная программа для Windows, которую поставляет ее
производитель, компания МОДУС ([swman.ru](http://swman.ru/)). **Отображает**
мнемосхемы сам Клиент ОИК встроенным модулем; устанавливать на рабочие места
компонент ActiveXeme для этого не нужно.

Готовую мнемосхему можно разместить двумя способами:

* скопировать файл в папку `%ProgramData%\Telecontrol\SCADA Client` на
  каждом рабочем месте Клиента ОИК. Эту папку можно открыть из Клиента
  командой меню *Настройки — Открыть папку мнемосхем*;
* загрузить файл один раз на Сервер, и тогда Сервер раздаст его всем
  Клиентам — смотрите [Серверные файлы]({{ '/dev/server-files/' | relative_url }}).

При добавлении новой схемы в папку рабочего места она будет доступна из главного меню `Схема` после перезапуска Клиента.

При изменения схемы или алиаса достаточно закрыть и повторно открыть схему в ОИК для применения изменений.

### Привязка объектов

Для привязки объекта ТС или ТИТ к мнемосхеме нужно задать алиас объекта. Это можно сделать в окне *Свойства*, открываемом одноименным пунктом контекстного меню объекта (поле «Алиас»). Допустимы алиасы, состоящие из английских и русских букв и цифр, но не содержащие пробелов.

После того, как алиас будет определен, его нужно привязать к элементу схемы. Объекты ТС привязываются к элементам мнемосхемы, имеющим свойство *положение*, а объекты ТИТ - к текстовым полям со свойством *текст*.

В Графическом редакторе выберите элемент мнемосхемы и укажите алиас, как значение для свойства `ключ_привязки` в окне *Редактор свойств элемента* (клавиша F11).

Для привязки произвольного свойства, используйте выражение вида *имя_свойства=алиас*

![]({{ '/img/modus-f11-bus.png' | relative_url }})

Для привязки нескольких свойств одного объекта используйте разделитель `;` (точку с запятой): *имя_свойства1=алиас1;имя_свойства2=алиас2*

![]({{ '/img/modus-f11-breaker.png' | relative_url }})

### Заголовок схемы

Заголовок [*Схемы*]({{ '/client/display/' | relative_url }}#goto-object) записывается в файлы c расширением *sde* и *xsde*. Он может быть изменен при помощи Графического редактора Модус, вызовом команды меню *Схема - Свойства страницы - О файле...* и заданием атрибута `Заголовок`:

![]({{ '/img/modus-scheme.png' | relative_url }})

В пункте главного меню Клиента `Схемы` будет отображаться текст, заданный в атрибуте `Заголовок`:

![]({{ '/img/menu-scheme.png' | relative_url }})
