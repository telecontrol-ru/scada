# Дизайнер — редактор схем Видикон
{:.no_toc}

* TOC
{:toc}

Дизайнер создает и редактирует схемы Видикон — файлы *vds* — и библиотеки
трафаретов — файлы *vdc*. Готовую схему показывает Клиент в окне
«Мнемосхема»; как элементы схемы получают значения объектов ОИК, описано в
разделе [Схемы Видикон]({{ '/dev/displays/' | relative_url }}#vidicon).

Подробно работа в Дизайнере описана на страницах раздела:

- [Рисование и правка]({{ '/dev/designer/drawing/' | relative_url }}) —
  инструменты, выделение, перемещение, поворот, группировка, порядок;
- [Оформление]({{ '/dev/designer/formatting/' | relative_url }}) — панель
  «Формат», диалоги линии, заливки, текста и поведения, стили, слои,
  свойства документа;
- [Трафареты]({{ '/dev/designer/stencils/' | relative_url }}) — символы,
  создание и правка трафаретов, библиотеки *vdc*;
- [Свойства и формулы]({{ '/dev/designer/properties/' | relative_url }}) —
  панели «Свойства», «Преобразование», «Пользовательские свойства», строка
  формул и справочник функций;
- [Линейки, сетка и вид]({{ '/dev/designer/view/' | relative_url }}) —
  масштаб, прокрутка, линейки, направляющие, сетка и привязка.

## Установка {#install}

Дизайнер входит в пакет Клиента для Windows `telecontrol-scada-<версия>.msi`,
который создает пиктограмму *Дизайнер* на рабочем столе и в меню
*Пуск — ОИК Телеконтроль*. **Для версии 2.6 этот пакет пока не опубликован**
— смотрите [Начало работы]({{ '/getting-started/' | relative_url }}).

## Окно Дизайнера {#window}

![Окно Дизайнера со схемой ТЭЦ-1]({{ '/img/designer-window.png' | relative_url }})

Сверху вниз:

- **Меню** — Файл, Правка, Вид, Формат, Фигура, Сервис, Окно, Справка.
- **Одна строка панелей инструментов**: *Стандартная* (создать, открыть,
  сохранить, отменить, повторить, вырезать, копировать, вставить),
  *Упорядочить* (выравнивание, порядок и группировка, поворот и отражение) и
  *Формат* (цвета, линии, стиль и шрифт). Если окно узкое, последние кнопки
  панели *Формат* — шрифт и выравнивание текста — уходят в меню `»` на ее
  правом краю.
- **Строка формул** — правка формулы выбранной ячейки выделенной фигуры
  (смотрите [Свойства и формулы]({{ '/dev/designer/properties/' | relative_url }}#formula-bar)).

![Панель «Стандартная»]({{ '/img/designer-toolbar-standard.png' | relative_url }}){: width="407"}

Слева — вертикальная панель *Инструменты* с инструментами рисования и
панели *Трафареты* и *Навигатор*. Справа — панель *Преобразование* и под ней
*Свойства* и *Пользовательские свойства*. Панели, сложенные вкладками,
переключаются вкладками над ними; закрыть или снова открыть любую панель,
строку формул или панель инструментов можно в меню *Вид*. Панели и панели
инструментов можно перетаскивать к другому краю окна; их расположение
запоминается.

Внизу — **строка состояния**:

- координаты указателя над схемой, например `X = 123.4    Y = 567.8`;
- сведения о выделении: для одной фигуры — имя, ширина, высота, угол и
  положение, для линии — длина, угол и смещения, для нескольких — их
  число, а если ничего не выделено — размер страницы, например
  `Страница 2760 × 1960`;
- переключатели *Сетка* и *Привязка* и масштаб: уменьшить, поле масштаба
  (выберите или введите, например, `150%`), увеличить, уместить в окне.

### Язык, стиль и визуализатор {#settings}

- *Вид — Язык* — язык интерфейса: русский, английский или язык системы.
  Действует после перезапуска.
- *Вид — Стиль* — стиль оформления окон; по умолчанию *Fusion*.
- *Вид — Визуализатор* — способ отрисовки схемы: *Scene* или *QPainter*, а в
  Windows еще *GDI+*. Там же переключатель *Сглаживание*: без него тонкие
  линии четче, со сглаживанием плавнее кривые.

Выбор запоминается для пользователя Windows.

## Файлы {#files}

| Команда | Сочетание |
|---|---|
| *Файл — Создать* | `Ctrl+N` |
| *Файл — Новый документ трафарета* | — |
| *Файл — Открыть...* (*vds*, *vdc*, *sde*, *xsde*) | `Ctrl+O` |
| *Файл — Сохранить* | `Ctrl+S` |
| *Файл — Сохранить как...* | — |
| *Файл — Последние файлы* | — |
| *Файл — Печать...* | `Ctrl+P` |
| *Файл — Предварительный просмотр...* | — |

Схема хранится в двоичном формате *vds*. В окне предварительного просмотра
можно сменить ориентацию страницы, масштаб и принтер, а затем напечатать.

**Мнемосхемы Модус** (*sde*, *xsde*) Дизайнер тоже открывает — чтобы перевести
их в формат Видикон: сохраняется такая схема через *Сохранить как...* и только
как *vds*; исходный файл Модус не меняется. Приборы, переключатели и кнопки
Модус рисуются собственными картинками Модус, если переменная окружения
`SCADA_MODUS_STENCIL` указывает на трафарет Модус (его один раз готовит
администратор из папки `dat` установленного Модус); иначе они рисуются
упрощенно. Тот же трафарет можно открыть через *Файл — Открыть трафарет...*,
чтобы ставить картинки и элементы Модус на схемы. После перевода проверьте
схему: элементы без аналога в Видикон могут выглядеть иначе.

## Вкладки, сохранение изменений и меню «Окно» {#tabs}

Каждая открытая схема — и каждый открытый на правку трафарет — отдельная
вкладка. Полоса вкладок появляется, когда открыта вторая схема; при одной
схеме ее имя видно в заголовке окна.

![Две открытые схемы]({{ '/img/designer-tabs.png' | relative_url }})

Измененная и еще не сохраненная схема отмечена звездочкой `*` на вкладке и
в заголовке окна. **Если закрыть такую схему** — вкладку, окно Дизайнера или
всю программу, — Дизайнер спросит, сохранить ли изменения:

![Вопрос о сохранении изменений]({{ '/img/designer-save-prompt.png' | relative_url }}){: width="473"}

*Сохранить* записывает файл (для новой схемы — спросив имя), *Не сохранять*
закрывает без записи, *Отмена* оставляет схему открытой. Если открыть файл,
пока впереди пустая новая схема *Без имени*, в которой ничего не меняли, файл
займет ее место.

Меню *Окно*:

| Команда | Сочетание | Действие |
|---|---|---|
| Следующее | `Ctrl+F6` | следующая вкладка |
| Предыдущее | `Ctrl+Shift+F6` | предыдущая вкладка |
| Закрыть | `Ctrl+F4` | закрыть текущую вкладку |
| Закрыть все | — | закрыть все вкладки |

Ниже меню перечисляет открытые схемы (текущая отмечена); первые девять
вызываются клавишами `Alt+1` … `Alt+9`.

## Сочетания клавиш {#keys}

*Справка — Сочетания клавиш* показывает все команды меню, у которых есть
сочетание. В macOS вместо `Ctrl` нажимайте `⌘`. Основные:

| Клавиши | Действие |
|---|---|
| `Ctrl+N` / `Ctrl+O` / `Ctrl+S` | Создать / открыть / сохранить |
| `Ctrl+Z` / `Ctrl+Y` | Отменить / повторить |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | Вырезать / копировать / вставить |
| `Ctrl+A` / `Ctrl+D` / `Delete` | Выделить все / дублировать / удалить |
| `Ctrl+G` / `Ctrl+Shift+G` | Группа / разгруппировать |
| `Ctrl+Shift+]` / `Ctrl+Shift+[` | На передний план / на задний план |
| `Ctrl+R` / `Ctrl+L` | Повернуть на 90° вправо / влево |
| `Alt+Enter` | Панель «Свойства» |
| `Ctrl++` / `Ctrl+-` / `Ctrl+0` | Увеличить / уменьшить / уместить в окне |
| `Alt+C` | Центрировать выделение |
| Колесо мыши / `Ctrl` + колесо (в macOS `⌘` + прокрутка) | Прокрутка / масштаб вокруг указателя |
| Пробел + перетаскивание | Сдвиг схемы |
| Стрелки (`Ctrl`, `Alt`) | Сдвиг выделения на деление линейки (шаг сетки, пиксель) |
| `Ctrl` + перетаскивание | Копировать выделение |
| `Ctrl+Shift+O` / `F3` | Открыть трафарет / трафареты по умолчанию |
| `Ctrl+F6` / `Ctrl+Shift+F6` / `Ctrl+F4` | Следующая / предыдущая / закрыть вкладку |
| `Esc` | Отменить текущее действие, выйти из правки текста |
