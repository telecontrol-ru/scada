# Серверные файлы

При использовании распределенной Клиент-Серверной архитектуры ОИК на базе многомашинного комплекса с выделенным центральным Сервером всю информацию о файлах мнемосхем Сервер предоставляет всем своим Клиентам автоматически.

Окно просмотра Серверных файлов можно вызвать командой `Файлы` из главного меню Клиента `Дополнительно`:

![]({{ '/img/files.png' | relative_url }})

В окне *Файлы* Серверные файлы мнемосхем могут быть организованы по нескольким вложенным папкам хранения. Двойной клик ЛКП по выбранному файлу мнемосхемы в окне *Файлы* приведет к его отображению в Клиенте.

## Как загрузить мнемосхему на Сервер

1. Откройте окно *Файлы* (*Дополнительно — Файлы*).
2. Чтобы создать папку, выберите в контекстном меню окна *Создать — Папка*.
3. Выделите папку, в которую нужно поместить файл, и выберите в контекстном
   меню *Создать — Файл*. В открывшемся окне выберите файл мнемосхемы
   (*sde* или *xsde*) на своем компьютере — он будет передан на Сервер.

Для загрузки файлов требуется право «Настройка конфигурации».

## Где файлы хранятся на Сервере

Сервер версии 2.6 хранит файлы в папке процесса `scada-filesystem`. На
установке, выполненной `scada-setup`, это

`%ProgramData%\Telecontrol\SCADA Server\filestore\FileSystem`

Сервер версии 2.5 хранил их в `%ProgramData%\Telecontrol\SCADA Server\FileSystem`;
при переходе на 2.6 они копируются в новую папку. Смотрите
[Серверная файловая система]({{ '/server/' | relative_url }}#filesystem).

Такой подход к хранению файлов мнемосхем предполагает, что достаточно изменить содержимое файла мнемосхемы в одном месте на Сервере, чтобы внесенные изменения автоматически вступили в силу сразу у всех Клиентов, подключенных к Серверу.
