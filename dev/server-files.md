# Серверные файлы

При использовании распределенной Клиент-Серверной архитектуры ОИК на базе многомашинного комплекса с выделенным центральным Сервером всю информацию о файлах мнемосхем Сервер предоставляет всем своим Клиентам автоматически.

Окно просмотра Серверных файлов можно вызвать командой `Файлы` из главного меню Клиента `Дополнительно`:

![]({{ '/img/files.png' | relative_url }})

В окне *Файлы* Серверные файлы мнемосхем могут быть организованы по нескольким вложенным папкам хранения (как создать папку — смотрите ниже). Двойной клик ЛКП по выбранному файлу мнемосхемы в окне *Файлы* приведет к его отображению в Клиенте.

## Как загрузить мнемосхему на Сервер

1. Откройте окно *Файлы* (*Дополнительно — Файлы*).
2. Выберите в контекстном меню окна *Создать — Файл*. В открывшемся окне
   выберите файл мнемосхемы (*sde*, *xsde* или *vds*) на своем компьютере — он
   будет передан на Сервер.

Команда *Создать — Папка* создает в выделенной папке новую папку с именем
«Новая папка»; затем переименуйте ее. Папки, которые уже есть на Сервере
(например, перенесенные с версии 2.5), отображаются в окне как обычно.

Для загрузки файлов требуется право «Настройка конфигурации».

## Где файлы хранятся на Сервере

Сервер версии 2.6 хранит файлы в папке процесса `scada-filesystem`. На
Сервере в облаке эту папку хранит и резервирует ООО «Телеконтроль»: файлы
загружаются и изменяются только из Клиента, как описано выше. Файлы
мнемосхем Сервера 2.5.7 переносятся при переходе на Сервер в облаке, который
согласуется с ООО «Телеконтроль» (смотрите
[Сервер 2.5.7 и установки на объекте]({{ '/server/' | relative_url }}#legacy)).

Такой подход к хранению файлов мнемосхем предполагает, что достаточно изменить содержимое файла мнемосхемы в одном месте на Сервере, чтобы внесенные изменения автоматически вступили в силу сразу у всех Клиентов, подключенных к Серверу.
